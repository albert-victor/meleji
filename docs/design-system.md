# Meleji Homestays – Design system

Shared visual foundation and completed homepage reconstruction.

## Typography

Cormorant Garamond 500 for editorial headings; Manrope 400–600 for body and UI. Two families throughout, including development preview pages. Section headings scale from 32 to 58px; editorial card titles from 24 to 34px. Component-specific sizes remain available for functional cards. Italic emphasis should be selective.

## Color and surfaces

Warm cream page background, brown headings, muted neutral body copy. Original logo accent tokens remain available. Editorial colors are provisional, not a newly asserted official palette. Primary CTA uses #b95118 → #a5451d → #873b22 with white text; hover darkens to #a5451d → #873b22 → #71301d. Gold is decorative, not small text on cream.

## Buttons and spacing

Soft rectangle by default; round modifier for selected booking actions. Minimum 44px button height, including small variants. Sliding labels share a 1.5em line box. Focus remains outlined; active state moves 1px; reduced motion disables label and active movement. Hover uses surface changes without heavy shadows. Shared section spacing scales from 48 to 96px. Added the missing space-14 token used by the hero.

## Motion and imagery

Reveal content stays visible without JavaScript. Opt-in is-visible animation uses opacity and transform; reduced motion removes it. Existing Font Awesome Free remains the icon system. Sections use authentic photography, deliberate overlaps and restrained patterns following the supplied references.
